이 화면은 어디서 데이터를 읽는가? (data sources)

CLI 모드 — npx know-thy-build factory board [--repo owner/name]…로 열면 로컬 프로세스가 /api/board(모델)와 /api/events(SSE)를 준다. 모든 GitHub 조회는 여러분의 gh CLI를 통해 나가므로 프라이빗 저장소도 그대로 보이고, 토큰은 브라우저에 들어오지 않는다. 기록 브랜치 (factory/records)의 완료 런 비용까지 합산된 완전한 모델은 이 경로에만 있다.

정적 모드 — 이 파일을 그냥 열거나 GitHub Pages에 올리고 ?repo=owner/name을 붙이면 페이지가 api.github.com을 직접 부른다. 인증 없이는 공개 저장소만, 시간당 60회다(남은 횟수는 오른쪽 위에 표시된다). 프라이빗 저장소는 아래 토큰 칸에 repo 스코프 토큰을 넣으면 되고, 그 값은 이 브라우저의 localStorage에만 저장된다 — 어디로도 전송되지 않는다. 이 모드의 비용 칩은 live(도는 런)만 센다.

읽는 신호 — 상태는 라벨, "언제부터"는 전이 코멘트(factory-transition:v1), "살아 있는가"는 하트비트 첫 줄, "지금 무엇을 하는가"는 그 코멘트의 factory-progress:v1 마커(ADR-022). 새 신호를 만들지 않는다 — 공장이 이미 남기는 것만 읽는다.
